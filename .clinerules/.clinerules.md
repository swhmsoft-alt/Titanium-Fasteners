# Cline 工作规约（v2 · 可执行优先）

> **设计原则：不写「请遵守」，只写「只有这一条路能走通」。**
> 散文规则在上下文压缩后会被优先丢弃，因此每条硬约束都对应一个可执行命令。
> 细则见 `docs/PRODUCT-DATA.md`（数据层约定），本页只保留闸门。

---

## 0. 三道闸门（每次开工按顺序跑）

| # | 命令 | 作用 | 失败时 |
| --- | --- | --- | --- |
| 0 | `npm run budget -- --reset` | 新原子任务开始时清零账本 | — |
| 1 | `npm run preflight -- <slug>` | 检查五项充分性 + 会话预算 + 残留探针 | **退出码 2，禁止进入写入阶段** |
| 2 | `npm run grep -- "<kw>" <path>` | 唯一合法的检索入口（限行宽/限命中数） | 换更精准的关键词 |
| 3 | `npm run budget` | 查看本会话读写/调用账本 | 超限就停手上报 |

`preflight` 的五项：路由与文件落点 · 真相源就绪 · 生成产物新鲜 · 素材本地路径 · 数据闸门。
**任一 ❌ 就是「信息不足」**，正确动作是补那一项，或直接问用户 —— 不是再探一轮。

### 0.1 数据层闸门

**产品数据层多一道闸门**：

| # | 命令 | 作用 | 失败时 |
| --- | --- | --- | --- |
| B1 | `npm run gen:products` | 校验 `data/products/*.csv` 并生成 `src/data/products/*.ts` | 退出码 1（0 error 才算通过） |

**产品数据铁律**
- `data/products/*.csv` 是唯一真相源；`src/data/products/**` 是**生成产物，禁止手改**（文件头有 BANNER 标记）。
- 页面只从 `@data/products` import，**禁止**直接读 CSV。
- 改规格矩阵 → 改 CSV → 跑 `npm run gen:products` → build。**禁止**改生成物。
- 详见 `docs/PRODUCT-DATA.md`。

## 1. 开工契约（首次工具调用前必须输出，≤6 行）

```
GOAL: <one sentence>
IN:   <source asset / path>
OPS:  <whitelist of allowed operations>
OUT:  <deliverable file list>
DONE: <machine-checkable completion signal>
```

契约一经输出即冻结；扩大 OUT/OPS 必须有用户新的明确指令。

---

## 2. 写入通道（Code-Creation Channel）

- >15 行的文件**只能**经 `write_file` / `editor` / 生成脚本一次性原子写入。
- 禁止先在对话里草拟文件正文再落盘；禁止分片写入；禁止写完再贴一遍。
- 对话是状态通道：只报文件路径 + ≤5 行事实摘要。**任何代码块 ≤15 行。**
- 交付物本身是代码时，给路径，不贴源码。

---

## 3. 探索预算（账本：`qa/.session/budget.json`）

由 `scripts/lib/session-budget.mjs` 记账，`preflight` 强制检查：

| 限制 | 值 | 说明 |
| --- | --- | --- |
| 同一路径**手读**次数 | ≤2 | 手抄/重读 = 浪费，硬卡 |
| 同一路径**生成器**消费次数 | ≤20 | 重跑生成器是正常修复手段 |
| 单原子任务工具调用 | ≤8 | |
| 单原子任务勘察类调用 | ≤6 | |
| `qa/` `scripts/` 残留探针（`_*.mjs/txt/json/log`） | 0 | 收据前必须清零 |

**读取已有生成产物优先于读源文件**：`src/data/products/**` 已是结构化结果。

## 4. 页面任务边界

- 新页面的 data 优先**脚本生成**（`scripts/gen-*.mjs`），不要手抄 DOM。
  抽取逻辑写进生成器，不要写进 data。
- 已知页型 = 只写 data + 复用组件；先查 `src/components/sections/`。
- **页面任务禁止改动全局 CSS、页头、页脚、导航。** 公共组件偏差单独立项。
- 页面级验收：`npm run build` 一次 + `npm run gen:products` 一次（0 error）。

### 4.1 岛屿（Island）选型

本仓库的岛目前只有一个：`src/components/islands/InquiryForm.tsx`（询盘表单）。

- **表单类转化组件用 `client:load`，不用 `client:visible`。**
  `client:visible` 只在元素滚入视口时 hydrate。若页面里有指向该元素的锚点链接
  （如规格表的「询盘」按钮跳 `#inquiry`），岛可能尚未接管 → 表单走原生 GET 提交
  → 页面刷新 → 询盘内容丢失。实测过的真实缺陷，不是理论风险。
- **岛内的数据一律构建期注入 props，不在运行时抓 DOM。** 无 JS 时也要能显示正确上下文。
- **岛读取 URL 状态（如 hash 里的 query）时，在渲染与提交时现读，不缓存。**
  同页 hash 跳转不触发 React 重渲染，缓存值可能是旧的。

## 5. 硬禁区

- 绝不读取/检索：`node_modules/` `.git/` `.astro/` `dist/` `build/` `.vercel/` `.netlify/`
- 检索只用 `npm run grep`（单关键词）；命中 >20 条立刻停止并要求用户缩小范围
- 大体积单行文件（HTML / 压缩 JSON）一律经 `npm run grep` 按字段抽取，**禁止**整读 / 裸 grep / 内联 PowerShell 正则
- 严禁直读原始构建日志；用 `Select-String -Path x.log -Pattern 'Complete!'` 过滤
- 编译错误 >5 条即停手上报，不继续自动修
- 同一命令失败两次即换路一次，再失败就上报
- **禁止任何跳转/重定向**（301 / 302 / `<meta http-equiv="refresh">` / `astro.config` 的 `redirects` / `Astro.redirect()` / 跳转 stub 页）：跳转层会把临时 URL 固化成永久契约，制造大量未知问题 —— 需要改 URL 时直接改路径，不留跳转

## 6. 收据（完工前）

```
DONE: <one line>
- Modified path (Lines X-Y)
- Assets: <new / converted files>
- Scratch removed: <list>
- Out-of-scope: <0 or leftover note>
- Output duplication: 0
```

临时脚本/日志/分析产物**必须**在收据前删除（`preflight` 会检查 `qa/` `scripts/` 的 `_` 前缀残留）。
