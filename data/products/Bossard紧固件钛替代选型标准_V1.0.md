## 2. 物理判据基准（选型的第一性依据）

### 2.1 密度与比强度

| 材质 | ρ g/cm³ | Rm MPa | 比强度 Rm/ρ | E GPa | 相对 Gr5 质量 |
|---|---:|---:|---:|---:|---|
| **Gr2 工业纯钛** | **4.51** | ≥345 | ≈76.5 | ≈104 | 重 1.8% |
| **Gr5 / TC4 (Ti-6Al-4V)** | **4.43** | ≥895（棒材） | **≈202** | ≈110 | 基准 |
| 不锈钢 A2 / 304 | 7.90 | 700（A2-70） | ≈88.6 | ≈193 | Gr5 减重 43.9% |
| 不锈钢 A4 / 316 | 8.00 | 700（A4-70）/ 800（A4-80） | ≈87.5 | ≈193 | Gr5 减重 44.6% |
| 碳钢 8.8 / 10.9 / 12.9 | 7.85 | 800 / 1040 / 1220 | 102 / 132 / 155 | ≈210 | Gr5 减重 43.6% |
| 铝合金 6xxx | 2.70 | ≈310~330 | ≈118 | ≈70 | Gr5 增重 64.1% |
| 黄铜 / 铜 | 8.50 / 8.96 | ≈350~500 | ≈41~56 | 110 / 120 | 已排除 |
| PA66 | 1.14 | ≈70 | ≈61 | 2~3 | 已排除 |

**三条衍生结论（不可跳过）**

1. **比强度 ≠ 绝对强度**。Gr5 比强度（≈202）约为 A2-70 的 2.3 倍、8.8 钢的 2.0 倍，甚至高于 12.9 钢（155）；但 12.9 的绝对抗拉 1220 MPa 仍高于 Gr5 的 895 MPa，故**同规格等强替代 12.9 不成立**。
2. **替代铝件是反向操作**。钛比铝重约 64%，轻量化诉求下不成立；仅在耐蚀、耐温、绝对强度成为瓶颈时才是"性能升级"，必须在报价文件中明确口径。
3. **E 只有钢的一半是密度的代价**。同几何下螺栓伸长约为钢件 2 倍：对抗疲劳、补偿热变形有利；但使弹簧类元件弹力减半、预紧—扭矩关系失效。**密度优势必须与刚度折减同步评估**。

### 2.2 强度标尺（双口径，按用途引用）

| 材料 / 等级 | Rm MPa | Rp0.2 / Re MPa | 延伸率 % | 硬度 HV | 引用规范 |
|---|---:|---:|---:|---:|---|
| Gr2（棒材） | ≥345 | ≥275 | 20–30 | 180–240 | ASTM B348 Gr.2 |
| **Gr5（棒材）** | **≥895** | **≥828** | 10–14 | 300–350 | ASTM B348 Gr.5 / AMS 4928 |
| Gr5（成品螺栓 ≤1-3/4″） | ≥931 | ≥827 | 10 | — | ASTM F593 Gr.5 |
| Gr5 ELI（植入级） | ≥860 | ≥795 | 10–15 | — | ASTM F136 / F1472 |
| 碳钢 8.8 | 800 | 640 | 12–15 | 200–250 | ISO 898-1 |
| 碳钢 10.9 | 1040 | 940 | 9–10 | 320–360 | ISO 898-1 |
| 碳钢 12.9 | 1220 | 1100 | 8 | 380–430 | ISO 898-1 |
| A2-70 / A4-70 | 700 | 450 | 20–30 | 250–320 | ISO 3506-1 |
| A4-80 | 800 | 600 | 20–30 | 250–320 | ISO 3506-1 |

**引用规则（强制）**：
- 设计校核用**棒材下限 895 / 828**（保守）。
- 成品螺栓出证书用**F593 口径 931 / 827**（小规格紧固件要求更高）。
- 医疗植入场景才引 ELI 的 860 / 795，**严禁与工业级混用**。

### 2.3 与各等级的对位关系

| 原材质 | 屈服对比（Ti − 原） | 判定 |
|---|---|---|
| 8.8（640） | Gr5 828 → **+29%** | ✅ 等强替代，有余量 |
| 10.9（940） | Gr5 828 → **−12%** | ⚠️ 降额 12% 或升一档规格 |
| 12.9（1100） | Gr5 828 → **−25%** | ❌ 同规格不成立，升 1–2 档或改 β 合金 |
| A4-80（600） | Gr5 828 → +38% | ✅ 覆盖 |
| A2/A4-70（450） | Gr5 828 → +84%；Gr2 275 → **−39%** | ✅ Gr5 升级；❌ Gr2 须降载约 50%（按抗拉） |
| 铝合金（≈240–280） | Gr2 275 → 基本对等 | ✅ 强度对等，但增重 64%，属性能升级 |

## 3. 牌号判定规则（决策树，写死）

```
原材质 / 等级                      → 推荐牌号与处理
碳钢 8.8                          → Gr5，等强替代（首选）
碳钢 10.9                         → Gr5 + 降额 12%（或升一档规格后按新 K 值标定）
碳钢 12.9                         → 不做同规格平替；升 1–2 档，或 β 合金 Ti-10V-2Fe-3Al（无标准件供应链）
不锈钢 A4-80                      → Gr5，等强 + 减重 + 抗点蚀
不锈钢 A2-70 / A4-70              → 承力件 Gr5；非承力/成本敏感件 Gr2，但按 50% 降载
铝合金 6xxx                        → Gr2，强度对等；须明确"增重 64%、性能升级"而非平替
弹簧钢（垫圈/挡圈）                → 不等几何替换：按 E 减半重设线径（×1.4）与行程，重新验证
黄铜 / 铜 / 塑料 / 易切削钢        → 排除（功能本体不匹配）
焊接类                            → 排除（现场工艺不可移植）
```

## 8. 工程红线（强制，8 条）

1. **禁止沿用钢制扭矩表。** `F = T / (K·d)`，Ti 干态 K ≈ 0.15–0.20、MoS₂ 干膜后 0.10–0.12，而 8.8 镀锌 K ≈ 0.14。沿用钢表 + 钛件润滑 → 预紧力超屈服 → 伸长过度、蠕变松弛、疲劳寿命骤降。做法：按目标预紧力反算扭矩，**扭矩-转角法**标定，目标预紧力取保证预紧力的 70–75%，公差带 ±10%（钢为 ±25%）。
2. **咬合（galling）是首要失效模式。** 钛钝化膜在拧紧时易冷焊撕裂。强制：**滚压螺纹（非车削）** + MoS₂/银基防咬合剂或干膜润滑 + 降低拧紧转速 + 禁止 Ti-Ti 干态装配 + 记录拆装次数。
3. **电偶方向不能搞反。** 电位序（NaCl 近似）：**Al ≈ −0.75 V < Ti ≈ −0.1~+0.1 V < 不锈钢/碳钢（钝化）≈ 0~+0.3 V**。钛是阴极，受害的是铝、镁、锌、碳钢基体；Ti + Al + 电解质会导致铝侧点蚀迅速扩展。做法：绝缘垫/套筒 + 密封胶 + 阳极氧化膜 + 控制"小阳极—大阴极"面积比；钛件优先用于钢/钛/镍基基体。
4. **氢脆与 α-case 必须管。** 酸洗（HF/HNO₃）吸氢，要求 **H ≤ 150 ppm**，酸洗后 4 h 内 130–175 °C 烘烤去氢；热加工后表面富氧 α-case 降低疲劳强度，须化学铣或机加工去除；避免与锌/镉镀层件在电解质中共存形成阴极吸氢。
5. **表面处理口径必须改写。** 钛不需要镀层防腐（TiO₂ 自修复）。可用方案仅：本色、硝酸钝化（ASTM F86）、阳极氧化（AMS 2488，可染色标识）、喷丸（疲劳）、MoS₂/干膜（防咬合）。对外报价把"镀层"改为"表面处理"，否则客户会拿锌片/热镀锌价格对比而无法成交。
6. **螺纹与旋合长度。** 滚压螺纹强制；标准螺母 **≥6 圈**全螺纹啮合，细牙 **≥8 圈**；螺母高度建议 1.0d；旋合长度不足是钛接头拉脱的主因（钛剪切承载低于钢）。
7. **温度边界。** Gr2 长期 ≈315 °C；Gr5 长期 315–350 °C、短时 400 °C；>300 °C 承力位改 Gr9（Ti-3Al-2.5V）；尼龙嵌件把上限拉回 ≈120 °C。低温（−196 °C）是钛相对碳钢的优势场景。
8. **富氧环境禁用 + 安全件必须试验。** 钛在富氧、高压氧、液氧中可燃，航空与医疗气体管路为硬红线；吊环等安全件替代必须做载荷试验，不得仅以材料论证替代。
