# Bossard 紧固件钛替代选型清单（Gr2 / Gr5-TC4）

> **数据来源**：`https://www.bossard.com/global-en/eshop/` 及 `01.100` / `01.300` 各级子类页面实时抓取；BN 号与 A2/A4 版本由 Bossard 中国、瑞士、美国、中国台湾、新加坡等产品页交叉核验。  
> **筛选口径**：优先 `Standard Fastening Elements`（01.100）与 `Securing and Anti-Loosening Elements`（01.300）；按原材质执行「高度匹配 / 谨慎评估 / 直接排除」三级判定；判定仅基于密度、强度、弹性模量、腐蚀电位、摩擦与成形性等工程物理特性。  
> **路径缩写**：`SFE` = `01.100 Standard Fastening Elements`；`SAE` = `01.300 Securing and Anti-Loosening Elements`。BN 为 Bossard 自有料号，均为站内实抓的代表性样本。

## 0. 密度与轻量化基准（选型的第一性判据）

| 材质                       | 密度 ρ (g/cm³) |     抗拉强度 σb (MPa) | 比强度 σb/ρ (MPa·cm³/g) | 弹性模量 E (GPa) | 与 Gr5 等体积质量对比     |
| ------------------------ | -----------: | ----------------: | -------------------: | -----------: | ----------------- |
| **Gr2 工业纯钛**             |     **4.51** |              ≥345 |                ≈76.5 |         ≈103 | 比 Gr5 重 1.8 %     |
| **Gr5 / TC4（Ti-6Al-4V）** |     **4.43** |     ≥895（可达 1100） |             **≈202** |         ≈114 | 基准                |
| 不锈钢 A2 / 304             |        ≈7.90 |        700（A2-70） |                ≈88.6 |         ≈193 | Gr5 减重 **43.9 %** |
| 不锈钢 A4 / 316             |        ≈8.00 |        700（A4-70） |                ≈87.5 |         ≈193 | Gr5 减重 **44.6 %** |
| 碳钢 / 合金钢（8.8~12.9）       |         7.85 | 800 / 1000 / 1200 |      102 / 127 / 153 |          210 | Gr5 减重 **43.6 %** |
| 铝合金                      |        ≈2.70 |          ≈300~400 |             ≈111~148 |          ≈70 | Gr5 **增重 64.1 %** |
| 黄铜 / 铜                   | ≈8.50 / 8.96 |          ≈350~500 |               ≈41~56 |   ≈110 / 120 | 已排除               |
| PA 6.6 / PE              | ≈1.14 / 0.95 |          ≈70 / 25 |             ≈61 / 26 |         ≈2~3 | 已排除               |

**减重率计算式**：`(ρ_原 − ρ_Gr5) / ρ_原`。对碳钢：(7.85 − 4.43) / 7.85 = **43.6 %**；对 A4：(8.00 − 4.43) / 8.00 = **44.6 %**。

**三条密度衍生结论**：

1. **Gr5 的比强度 ≈202，约为 A2-70（88.6）的 2.3 倍、8.8 钢（102）的 2.0 倍，甚至高于 12.9 级钢（153）**——这正是"等强度大幅减重"或"等质量大幅提强度"的物理依据，也是替代 A2/A4 与 8.8 的最强卖点。但**比强度≠绝对强度**：12.9 的 1200 MPa 绝对值仍高于 Gr5，故 12.9 不可替代。
2. **替代铝件是反向操作**：钛比铝重约 64 %，轻量化诉求下不成立，仅在耐蚀、耐温（Gr5 可达 400 °C vs 铝约 150 °C）、绝对强度成为瓶颈时属于"性能升级替代"，必须在清单中单列说明。
3. **E 仅约钢的一半（114 vs 210 GPa）是密度的"副作用"**：同几何下螺栓弹性伸长约为钢件 2 倍，有利抗疲劳与补偿热变形，但使弹簧类元件弹力减半、预紧—扭矩关系失效。密度优势必须与刚度折算同时评估。

## 5. 落地必检项（跨品类通用）

1. **咬合（Galling）是首要失效模式**：钛钝化膜在拧紧时易冷焊撕裂。强制要求滚压螺纹（非车削）、MoS₂ / 银基防咬合剂或干膜润滑、降低拧紧转速，并禁止钛螺母—钛螺栓干态装配。Bossard 自身在 BN 33023 / 33064 上就用镀锌与 Delta-Seal 抑制不锈钢咬合，钛的该风险更严重。
2. **电偶腐蚀方向易被搞反**：钛是阴极（高电位），与铝、碳钢、锌、镁连接时**加速的是基材腐蚀**。必须用钛 / 绝缘平垫圈、绝缘套筒、涂层、密封胶与排水设计，并控制"小阳极—大阴极"面积比。
3. **扭矩必须重新标定**：锌片涂层 ISO 10683 明示 µ=0.12–0.18，钛无涂层时 µ 更高且离散；叠加 E 降低带来的螺栓刚度变化，8.8 / 10.9 原拧紧扭矩表完全不可沿用，建议扭矩-转角法 + 接头实测 K 系数。
4. **强度等级标记与认证**：换料后头部标记、性能等级、材质证明（ASTM B348 棒材 / F468 成品紧固件、EN 10204 3.1）须重建；Bossard 目录中的 DIN 912、DIN 934、DIN 933、DIN 7991、DIN 127 均标注为 "Standard withdrawn"，换料时应同步迁移到 ISO 4762 / 4032 / 4017 / 10642 现行标准，避免双重变更叠加风险。
5. **成本与温度边界**：钛紧固件约为同规格不锈钢的 5–15 倍，仅在减重、海水 / 氯离子长效免维护、无磁、生物相容、真空洁净等场景成立；Gr2 长期使用温度约 ≤315 °C、Gr5 约 400–450 °C，热态承载与高温氧化需单独评估；尼龙嵌件锁紧螺母会把耐温上限拉回约 120 °C。
6. **优先落地顺序**：`平垫圈 DIN 125（Gr2）` → `内六角圆柱头 DIN 912（Gr5）` → `外六角 DIN 931/933（Gr5）` → `六角螺母 DIN 934（Gr5，配 A4 螺母过渡）` → `紧定 / 盘头 / 沉头系列` → 最后才评估防松件。
