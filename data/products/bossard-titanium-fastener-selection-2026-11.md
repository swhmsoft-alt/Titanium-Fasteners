### 1.2 牌号选择判定规则（写死，不要凭感觉）

```
if 原材质 == 碳钢 8.8        → Gr5 (TC4)，安全升级
if 原材质 == 碳钢 10.9       → Gr5 (TC4)，等强度替换
if 原材质 == 碳钢 12.9       → 不做同规格平替；改 Gr5 + 加大规格，或走 β 合金（Ti-10V-2Fe-3Al）
if 原材质 == 不锈钢 A4-80    → Gr5 (TC4)，等强度 + 减重 + 抗点蚀
if 原材质 == 不锈钢 A2/A4-70 → Gr2 (CP-Ti) 走耐蚀路线，但必须降载；承力件一律 Gr5
if 原材质 == 铝合金          → Gr2，强度对等且耐蚀性大幅提升
if 原材质 == 弹簧钢          → Gr5，但刚度/行程必须重新计算
if 原材质 == 黄铜/铜/塑料/易切削钢 → 排除
```

### 1.3 钛的三个"反直觉"硬约束（决定哪些品类不能做）

| 约束 | 物理机理 | 工程后果 |
|---|---|---|
| **导热率只有钢的 1/7**（Gr5 6.7 vs 钢 50 W/m·K） | 拧紧时摩擦热全部滞留在螺栓内 | 螺栓升温→弹性模量下降→**预紧力松弛**；不能沿用钢的扭矩表；必须用角度-扭矩法/液压拉伸，且冷却后复检 |
| **弹性模量只有钢的 1/2**（110 vs 210 GPa） | 同样尺寸下弹性变形大一倍 | ① 弹簧垫圈刚度降 ~47% → 同刚度需线径 ×1.4；② 螺纹咬合长度需增加 30–50% 才达到同等剪切承载；③ 螺栓伸长量大，疲劳松弛更快 |
| **缺口敏感 + 耐磨差** | Ti-6Al-4V 缺口敏感度高于钢 | 螺纹**必须滚压成型**（不得车削），否则疲劳寿命衰减 3–5 倍；齿形/锯齿类垫圈无法保持锐利齿形 |

## 5. 通用工程注意事项（钛紧固件"五不要"）

### 5.1 不要沿用钢的扭矩表
- 预紧力公式 `F = T / (K·d)`。Ti-6Al-4V 干态 K ≈ 0.15–0.20，涂 MoS₂/干膜润滑后 **K 可降至 0.10–0.12**；而 8.8 钢镀锌 K ≈ 0.14、涂油 ≈ 0.11。
- **后果**：沿用钢扭矩表 + 钛件润滑 → 预紧力超出 Gr5 屈服 → 螺栓伸长过度、蠕变松弛、疲劳寿命骤降。
- **做法**：按目标预紧力反算扭矩并做**扭矩-角度法**标定；建议目标预紧力取材料保证预紧力的 70–75%，公差带 ±10%（钢为 ±25%）。

### 5.2 不要用"热镀锌 + 钝化"那套表面逻辑
- 钛不需要镀层防腐（TiO₂ 钝化膜自修复）。可用的表面方案只有：**本色（自然氧化）、硝酸钝化（ASTM F86）、阳极氧化（AMS 2488，含染色做标识）、喷丸（疲劳）、MoS₂/干膜（防咬合）**。
- 对外报价时必须把"镀层"改成"表面处理"口径，否则客户会拿锌片/热镀锌价格对比而无法成交。

### 5.3 不要在铝结构上直接用钛螺栓（除非绝缘）
- 电偶电位（NaCl 溶液近似）：**Al ≈ −0.75 V < Ti ≈ −0.1～+0.1 V < 不锈钢/碳钢（钝化）≈ +0.0～+0.3 V**。钛是贵金属电位。
- Ti 螺栓 + Al 基体 + 电解质 → **铝被腐蚀**，钛成为阴极，极板面积比悬殊 → 铝侧点蚀迅速扩展。
- Ti 螺栓 + 碳钢基体 → 钢成为阳极，在缝隙处加速腐蚀（比钢-钢更严重）。
- **正确做法**：钛件只用于**钢/钛/镍基合金基体**；用于铝件时必须加**绝缘垫圈 + 密封胶 + 阳极氧化膜**，或直接改用铝螺钉+不锈钢垫片。

### 5.4 不要让钛与钢直接"咬合"（galling）
- 钛抗咬合性好于钢，但**钛对铝、钛对钢在无润滑的高预紧下仍会微焊接咬死**（软金属对软金属更严重）。
- 装配规范：螺纹涂 MoS₂ 干膜或 NASA-approved 润滑剂；接触面用同一处理；拆装需记录次数。
- **滚压螺纹是强制项**（不是优选项）：车削螺纹的缺口半径大，Ti-6Al-4V 缺口敏感，疲劳寿命可差 3–5 倍。

### 5.5 不要忽视氢脆与 α-case
- 酸洗（HF/HNO₃）会吸氢。**要求 H ≤ 150 ppm（NASM 8846）**，酸洗后 4 h 内 130–175 °C 烘烤去氢。
- 热加工/热处理后表面 α-case（富氧层）会降低疲劳强度 → 必须化学铣（c milling）或机加工去除。
- 与钢、锌、镉共处电解质中可能发生阴极吸氢 → 避免钛与锌/镉镀层紧固件配对。
