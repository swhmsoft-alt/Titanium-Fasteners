1. **骨架取 B**：唯一给出可复现抓取方法与全量 SKU 计数的版本，作为目录与数值基准。

5. **数值冲突优先判别"标准适用对象是否不同"**：能用分层解释的不强行取一；确属分歧的，取更保守且有工程依据的一侧，并在 §0.3 留痕。

### 1.3 牌号选择判定规则（执行用，不凭感觉）

```
if 原材质 == 碳钢 8.8          → Gr5 / TC4：等强替换（唯一硬约束是重标扭矩）
if 原材质 == 碳钢 10.9         → Gr5：条件性替换，须重算预紧与保证载荷，不得 1:1 换料
if 原材质 == 碳钢 12.9         → 不做同规格平替；升 1–2 级规格或改 β 合金（Ti-10V-2Fe-3Al / Ti-6242）
if 原材质 == 不锈钢 A4-80      → Gr5：等强 + 减重 + 抗点蚀
if 原材质 == 不锈钢 A2/A4-70   → 承力件一律 Gr5；Gr2 仅耐蚀非承力且必须降载（Gr2 强度低于 A2-70）
if 原材质 == 铝合金            → Gr2 强度对等但增重约 64–67 %（Gr5／Gr2 口径），属「性能升级」非平替，必须单列说明
if 原材质 == 弹簧钢            → 原则上排除；仅几何锁紧型可列专项验证
if 原材质 == 黄铜/铜/塑料/易切削钢/焊接件 → 排除
if 功能核心为非金属嵌件（PA66）→ 排除，改全金属结构
--- 通用红线 ---
承力 → Gr5；纯耐蚀／非承力／同电位过渡 → Gr2；Gr2 禁止用于承力主结构
```

## 6. 通用工程红线（必须写进工艺卡，三份去重合并）

### 6.1 咬合（Galling）是头号失效模式

钛钝化膜在拧紧时易冷焊撕裂，**Ti-Ti 螺纹副风险最高**。强制：滚压螺纹（非车削，车削疲劳寿命差 3–5 倍）、MoS₂／银基防咬合剂或干膜润滑、降低拧紧转速、**禁止 Ti-Ti 干态装配**。Bossard 自身在 BN 33023／33064 上就用镀锌与 Delta-Seal 抑制不锈钢咬合，钛的该风险更严重。

### 6.2 扭矩必须重新标定

`F = T / (K·d)`。钛 K 值离散远大于钢：**干态 0.15–0.25、MoS₂／干膜润滑 0.10–0.12**（钢镀锌约 0.14、涂油约 0.11）。叠加 E 降低导致的螺栓刚度变化，**8.8／10.9 原拧紧扭矩表完全不可沿用**。做法：按目标预紧力反算扭矩、扭矩-转角法标定、目标预紧力取保证预紧力的 70–75 %（公差带 ±10 %，钢为 ±25 %）、**装配冷却后复检预紧力**（建议 30 min）。

### 6.3 电偶腐蚀方向易被搞反 +「同电位」≠「绝缘」

电偶电位（NaCl 溶液近似）：**Al ≈ −0.75 V < Ti ≈ −0.1～+0.1 V < 钝化不锈钢／碳钢 ≈ +0.0～+0.3 V**。钛是阴极（高电位），与铝、碳钢、锌、镁连接时**加速的是基材腐蚀**，并须控制「小阳极—大阴极」面积比。

- **同电位过渡**（钛／Gr2 垫圈、同批号配套）：消除螺栓—垫圈—螺母之间的电位差，是「整套钛接头」的价值。
- **电绝缘隔离**（非金属绝缘垫圈、绝缘套筒、涂层、密封胶、排水设计）：阻断电子通路，是钛件用于铝／碳钢基体的**唯一有效手段**。
- **钛垫圈不能充当绝缘隔离件**（修正 A 的表述）。钛件优先用于钢／钛／镍基合金基体。

### 6.4 表面处理与氢／α-case

钛不需要镀层防腐（TiO₂ 钝化膜自修复）。可用方案仅：**本色自然氧化、硝酸钝化（ASTM F86）、阳极氧化（AMS 2488，含染色标识）、喷丸（疲劳）、MoS₂／干膜（防咬合）**。**禁电镀、禁酸洗**：酸洗（HF/HNO₃）吸氢，要求 **H ≤ 150 ppm（NASM 8846）**，酸洗后 4 h 内 130–175 °C 烘烤去氢；热加工后 α-case（富氧层）须化学铣或机加工去除；避免钛与锌／镉镀层紧固件配对。对外报价须把「镀层」改成「**表面处理**」口径。

### 6.5 强度等级标记与认证

**没有「8.8 级钛螺栓」这种说法**——ISO 898-1 不覆盖钛。交付须按 **ASTM F593（螺栓）／F467（螺母）／F468** 或企业标准，附批次力学与硬度报告 + **ASTM B348／AMS 4928 棒材材质证明 + EN 10204 3.1（或 3.2）**。换料后头部标记、性能等级须重建，并同步完成 §2.4 的 DIN→ISO 标准迁移，避免双重变更叠加风险。

### 6.6 温度与成本边界

Gr5 长期承力 **≤315 °C**、Gr2 约 ≤300 °C，超温蠕变导致预紧松弛；尼龙嵌件结构把上限拉回约 **120 °C**；低温（−196 °C）反而是钛相对碳钢的优势场景。成本按 §3.5 两个口径分别说明，平替只在减重／耐蚀／无磁／失效代价／可追溯性能覆盖成本差时成立。

### 6.7 禁止场景

富氧／液氧环境禁用（§5.1）；现场焊接工艺不可移植；Ti-Ti 干态装配禁止；钛屑排屑与锥面划伤须控制。

### 6.8 整套配套与优先落地顺序

**只卖钛螺栓不卖钛螺母／垫圈，会让客户自行混搭 → 直接制造电偶腐蚀事故**。「整套钛接头」才是卖点，配套件必须同批号。优先落地顺序：  
`Gr2 平垫圈 DIN 125 A` → `Gr5 内六角圆柱头 ISO 4762` → `Gr5 沉头 ISO 10642` → `Gr5 外六角 ISO 4014／4017` → `Gr5 六角螺母 ISO 4032（过渡期配 A4-70）` → `紧定（平端·柱端）／盘头／低头系列` → `最后才评估防松件`。

## 7. 落地路线

### 7.1 品类策略

1. **不要做全目录**。按 §1.4 的 P0／P1／P2／不碰四级推进。
2. **两个牌号分工**：Gr2 只做**垫圈 + 低载紧定螺钉 + 薄螺母 + 小规格非承力件**（成本敏感、不承力）；Gr5 做**所有承力件**。Gr2 冒充 A2／A4-70 承力件是错误定位。
3. **配套件必须同批**，以「整套钛接头」交付，避免客户混搭产生电偶腐蚀退货。
4. **不做 12.9 等强替代、不做 DIN 127、不做未核实的 NORD-LOCK**。

### 7.2 面向欧洲买家的叙事与报价口径（B 的核心商业结论）

- 不讲「中国钛便宜」（欧洲买家对宝鸡钛质量有历史刻板印象），讲 **EN 10204 3.1／3.2 材质证书 + NASM 8846 氢含量控制 + ASTM B348／AMS 4928 双标准符合性 + 阳极氧化 AMS 2488 + 英文明细表（可与 Bossard eShop 数据结构对齐）**。
- **对标锚点是 Bossard 的「空目录」**：该品牌在两个核心大类 998 SKU 上零钛覆盖，其客户（欧洲分销 + 机械制造）正是钛紧固件终端需求方。切入话术：**「我们能按你 Bossard 的 BN 号对应表提供同标准钛件」**。
- 报价单与图纸**以现行 ISO 主标准引用**（§2.4），表面项写「表面处理」而非「镀层」（§6.4），力学值以**成品件口径**标注标准号（§3.1）。
