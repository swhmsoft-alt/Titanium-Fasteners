## 1. Step 1 · 跨文档工程冲突仲裁

三份报告在 12 处存在结论冲突。以下为最终仲裁结论，理由逐条给出。

### 1.1 NORD-LOCK® 楔形锁紧垫圈（`01.300.100.50`）→ **排除纯钛化，列专项验证**

| 文档 | 主张 |
|---|---|
| 报告 B（工程判据版） | Tier A 有条件推荐，"几何锁紧以张力代替摩擦，原理上不依赖材料摩擦特性" |
| 报告 C（类目分节版） | 直接排除，"依赖表面硬化高钢高硬度，钛会压溃咬合" |

**仲裁：排除。** B 的论证只覆盖了"垫圈副**内部**"——楔形凸轮与齿面之间靠几何锁紧替代摩擦；但**齿面与被夹件表面之间**仍是摩擦 + 微咬合，而 Nord-LOCK 官方材质只有钢 / A2 / A4 / 表面硬化不锈钢，**无钛牌号**（B 自己也标了 `[待核]`）。Gr5 硬度 HV 300–350，在楔形集中载荷下齿尖会塑性压溃，几何锁紧在 2–3 个循环内失效；叠加凸轮/螺栓头承压面的 Ti-Ti 咬合，与 C 的结论一致。

**唯一保留形态**：钢齿片 + 钛基体复合（项目制，P2），不进标准目录。

### 1.2 全金属锁紧螺母（DIN 980 V / ISO 7042）→ **牌号与工艺待专项验证（V1），不列 P0**

**仲裁结论：先纠正一处标准错标 —— 对外不得写 "DIN 980 / ISO 7042" 等效。**
ISO 7042 属 ISO 7040 系列，而 7040 系列（7040 / 7043）按三份报告自身的分类属**尼龙嵌件型**，与 DIN 980（全金属变形螺纹型）不同族。`standards.csv` 中该条目的 `iso` 列应**留空**。

**牌号仲裁**：三份报告的工程理由其实一致 —— 都承认 980 V 靠冷态塑性变形、需高延性。
- 报告 A 选 Gr2（延伸率 20–30 %，适合冷态压扁），但 Gr2 屈服仅 275 MPa；
- 报告 B/C 选 Gr5（强度足），但延伸率仅 10–14 %、变形窗口窄。

按合并版 §0.2 原则 4（可复现一手数据 ＞ 工程物理必然性 ＞ 多数一致 ＞ **保守侧**）：牌号分歧未闭合 → **列 Tier B 专项验证 V1**，不列 P0。

**工艺路线（按 V1 验证项落地）**：
- 路线 1：Gr2 压扁式 —— 延性够，强度不足，仅低载；
- 路线 2：Gr5 退火态 + 更大过盈量 —— 强度足，变形窗口窄，**禁止冷压**（会开裂）。
- 必做验证：≥10 次重复装拆自锁扭矩保持率、批次一致性、保证载荷试验、首次塑性扭矩标定。

> 该品类 BN（64、169、5242、6782、6865、19174、19175、40036、80046、85330）已在 CSV 中标 `status=verify`，**未纳入上架清单**。

### 1.3 力学标准引用体系 → **分层并列，对外用成品件口径**

| 报告 | Gr5 屈服引用 | 适用对象 |
|---|---|---|
| A | ≥828 MPa（ASTM B348） | **棒材** |
| B | ≥862 MPa（AMS 4928） | **航空锻件** |
| C | ≥827 MPa（ASTM F593） | **成品紧固件** |

**仲裁：不是矛盾，是分层。** 对外报价与网站参数表统一采用**成品件口径**：

| 用途 | 引用标准 | Gr5 数值 | Gr2 数值 |
|---|---|---|---|
| 进货检验 / 材质证明 | ASTM B348（棒材）、EN 3.7035 | 屈服 ≥828 MPa、抗拉 ≥895 MPa | 屈服 ≥275、抗拉 ≥345 |
| **交付验收 / 设计许用值** | **ASTM F468（螺钉）、F467（螺母）、F593** | 屈服 ≥827–828 MPa、抗拉 ≥895 MPa | 屈服 ≥345（≤3/4″） |
| 航空件补充符合性 | AMS 4928 | 屈服 ≥862 MPa、抗拉 ≥900 MPa | — |

**网站参数表写法**：主标准引用 F468 / F467，材料栏并列写 "ASTM F468 / ASTM B348"，航空客户可加注 AMS 4928。**禁止**把 862 当通用屈服值对外报（承诺兑现不了）。

### 2.4 牌号判定规则（执行用，不凭感觉）

```
原材质 == 碳钢 8.8            → Gr5：等强替换（唯一硬约束是重标扭矩）
原材质 == 碳钢 10.9           → Gr5：条件性替换，须重算预紧与保证载荷，不得 1:1 换料
原材质 == 碳钢 12.9           → 不做同规格平替；升 1–2 级规格或改 β 合金
原材质 == 不锈钢 A4-80        → Gr5：等强 + 减重 + 抗点蚀
原材质 == 不锈钢 A2/A4-70     → 承力件一律 Gr5；Gr2 仅耐蚀非承力且必须降载
原材质 == 铝合金              → Gr2 强度对等但增重 64 %，属「性能升级」非平替，单列说明
原材质 == 弹簧钢              → 原则上排除；仅几何锁紧型可列专项验证
原材质 == 黄铜/铜/塑料/易切削钢/焊接件 → 排除
功能核心为非金属嵌件（PA66）  → 排除，改全金属结构
--- 通用红线 ---
承力 → Gr5；纯耐蚀／非承力／同电位过渡 → Gr2；Gr2 禁止用于承力主结构
```

### 2.5 工艺路线取值域（已按族固化）

| 路线 | 适用 | 强制约束 |
|---|---|---|

| ISO 粗牙螺纹 `d1 max` 公共列 | 螺纹外径 | 全部 |
| 全螺纹物理关系 | `b`（螺纹长）= 全长 `L` | 全部 |

抽取器：`scripts/gen-bossard-dimensions.mjs`（可重跑，`--apply` 幂等合并）。
